Simulator Blok · Kode · Flowchart

Susun program dengan blok, tulis langsung sebagai kode Python, dan lihat flowchart-nya terbentuk otomatis. Ketiganya selalu sinkron — ubah di satu tempat, dua lainnya ikut berubah. Jalankan langkah demi langkah untuk melihat alur eksekusi dan isi variabel.

LED
Pilih contoh, susun blok, atau tulis kode — lalu tekan Jalankan atau Langkah.
Blok
Seret blok ke kanvas, atau klik blok lalu klik di kanvas untuk memilihnya: blok baru masuk ke dalam blok terpilih (if/while/for) atau tepat setelahnya.

Flowchart
Klik simpul untuk mengedit atau menghapusnya. Klik tombol + pada garis panah untuk menyisipkan blok.
Desain Flowchart
Seret simbol ke kanvas, geser untuk memindah, klik dua kali untuk mengedit teks. Seret titik kuning pada simbol ke simbol lain untuk membuat panah. Keputusan punya dua titik: Ya (kiri) dan Tidak (kanan), keduanya wajib tersambung.

Cara pakai & bahasa yang didukung
  • Blok: seret dari palet (atau klik), isi kotak putih dengan ekspresi Python, mis. nilai >= 75. Kotak merah = isian salah. Tombol ↑ ↓ ✕ memindah/menghapus; + elif dan + else melengkapi blok if.
  • Kode: subset Python — print(), input() (dibungkus int()/float() bila perlu), assignment = += -= *= /= //= %=, if / elif / else, while, for i in range(...), serta led_on() / led_off() untuk LED virtual. Fungsi: int float str abs round max min len. Komentar # diperbolehkan tapi tidak ikut ke blok. Kode yang belum valid tidak mengubah blok/flowchart; pesan kesalahan muncul di bawah editor.
  • Flowchart: bisa diedit — klik simpul untuk mengubah isinya atau menghapusnya, klik + pada garis untuk menyisipkan blok baru; kode dan blok ikut berubah. Bentuk: persegi panjang = proses, jajar genjang = input/output, belah ketupat = keputusan/perulangan. Saat eksekusi, simpul yang sedang dijalankan menyala di blok, kode, dan flowchart sekaligus.
  • Desain: nyalakan panel Desain untuk menggambar flowchart bebas (seret simbol, sambung dengan panah). Tulis isi simbol dalam Python (x = 5, print(x), nilai >= 75) atau singkat: input nilai, cetak x. Tombol Konversi memeriksa alurnya lalu membuat blok & kode; Ambil dari program memuat program ke kanvas.
  • Eksekusi: Langkah menjalankan satu perintah per klik; Jalankan berjalan otomatis (atur kecepatan); Jeda menghentikan sementara. Mengubah program saat berjalan akan menghentikannya.
  • Batasan: belum ada list, fungsi buatan sendiri, f-string, break/continue. Angka bulat hasil / (mis. 4/2) tampil 2, bukan 2.0.
